upupup 개인정보처리방침

시행일: 2026년 10월 6일

upupup(이하 "앱")은 사용자의 컴퓨터에서 실행되어, 사용자가 고른 영상 파일을 사용자의 유튜브 채널에 올려 주는 도구입니다. 이 방침은 앱이 구글 계정에서 어떤 정보에 접근하고 그것을 어떻게 다루는지 설명합니다.

1. 앱이 접근하는 구글 사용자 데이터

요청 권한접근하는 데이터쓰는 목적
youtube.upload사용자 채널에 동영상을 올리고 그 동영상의 정보를 정하는 권한사용자가 고른 영상을 올리고 제목·설명·태그·공개 상태·예약 시각·썸네일을 사용자가 정한 대로 넣기 위해
youtube.readonly연결된 채널의 이름과 ID, 사용자가 올린 동영상의 처리 상태어느 채널에 연결됐는지 화면에 보여 주고, 올린 영상이 제대로 처리됐는지 확인하기 위해

앱은 위 두 권한 밖의 구글 데이터(이메일 내용, 연락처, 드라이브 파일 등)에 접근하지 않습니다.

2. 데이터를 저장하는 곳

  • 구글이 발급한 접근 토큰과 갱신 토큰, 연결된 채널의 이름과 ID, 업로드 기록은 사용자의 컴퓨터 안에만 저장됩니다.
  • 앱 운영자는 서버를 두고 이 정보를 모으지 않습니다. 운영자는 사용자의 토큰이나 채널 정보를 받지 않습니다.
  • 영상 파일은 사용자의 컴퓨터에서 구글(유튜브) 서버로 직접 전송됩니다.

3. 데이터의 공유와 이전

  • 앱은 구글 사용자 데이터를 제3자에게 팔거나 넘기지 않습니다.
  • 구글 사용자 데이터를 광고, 신용 평가, 인공지능 모델 학습에 쓰지 않습니다.
  • 사용자가 직접 알림 기능을 켠 경우에 한해, 업로드 결과(영상 제목과 주소)가 사용자 본인이 지정한 알림 수신처로 전달될 수 있습니다.

4. 구글 API 서비스 사용자 데이터 정책 준수

upupup이 구글 API에서 받은 정보를 사용하고 다른 앱으로 이전하는 방식은 Google API 서비스 사용자 데이터 정책을 따르며, 여기에는 제한적 사용(Limited Use) 요건이 포함됩니다.

앱은 YouTube API 서비스를 사용합니다. 앱을 쓰는 사용자는 YouTube 서비스 약관에 동의하는 것이며, 구글이 정보를 다루는 방식은 Google 개인정보처리방침에서 볼 수 있습니다.

5. 보관 기간과 삭제

  • 토큰과 채널 정보는 사용자가 채널 연결을 끊거나 앱의 설정 파일을 지울 때까지 사용자의 컴퓨터에 남습니다.
  • 연결을 끊으려면 앱에서 채널 연결을 해제하거나, 구글 계정의 서드 파티 액세스 관리에서 upupup의 접근 권한을 삭제합니다. 권한을 삭제하면 앱은 더 이상 사용자의 유튜브 채널에 접근할 수 없습니다.
  • 운영자가 따로 보관하는 사용자 데이터는 없으므로, 운영자에게 삭제를 요청할 데이터도 없습니다. 그래도 궁금한 점이 있으면 아래 연락처로 문의해 주세요.

6. 어린이

앱은 만 14세 미만 어린이를 대상으로 하지 않으며, 어린이의 정보를 알면서 수집하지 않습니다.

Privacy Policy (English summary)

Effective: October 6, 2026. upupup runs on the user's own computer and uploads the user's selected video files to the user's own YouTube channel.

  • Data accessed: With youtube.upload the app uploads videos chosen by the user and sets their title, description, tags, privacy status, scheduled time and thumbnail. With youtube.readonly the app reads the connected channel's name and ID and the processing status of the user's uploaded videos. No other Google data is accessed.
  • Storage: OAuth access and refresh tokens, the channel name and ID, and upload history are stored only on the user's computer. The operator runs no server that collects this data and never receives it.
  • Sharing: Google user data is not sold or transferred to third parties and is not used for advertising, credit evaluation, or training AI models. If the user enables notifications, upload results (video title and URL) may be sent to a destination the user specifies.
  • Limited Use: upupup's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
  • YouTube API Services: The app uses YouTube API Services. By using it, users agree to the YouTube Terms of Service; see also the Google Privacy Policy.
  • Retention and deletion: Data stays on the user's computer until the user disconnects the channel or deletes the app's settings. Access can be revoked at any time at myaccount.google.com/permissions.
